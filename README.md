# Meu Primeiro PR

Este é um repositório de exemplo criado para praticar o fluxo de Pull Request no GitHub.

## Objetivo

Aprender a:

- Criar uma branch
- Fazer uma alteração
- Abrir um Pull Request
- Revisar e fazer merge

## Como contribuir

1. Crie uma branch a partir da `master`
2. Faça sua alteração
3. Abra um Pull Request descrevendo o que mudou
